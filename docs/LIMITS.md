# Limits

- **No lawyer has validated** any finding, playbook, position, item or answer key. Every finding is a prompt for a lawyer's judgement, never a substitute for it. Nothing here measures time saved.
- **Layer A is constructed, not real negotiations.** Its items were written by three model families, one of which (Claude) is also under test. The by-author analysis did not detect a self-advantage for Opus or DeepSeek, but it can only detect a large one; it did detect one for GLM-5.3 Flash.
- **The frozen layer A set is small** (28 verified single deviations), so a perfect score has a wide bound: "0 of 28 missed" means fewer than about 1 in 9 with 95% confidence. One run per setup; run-to-run variation is not measured. Layers H, B and C are preliminary.
- **Costs for the open models are estimates:** tokens used × Munito's listed prices, not a bill. Opus costs are the API-equivalent figures Claude Code reports. Times include queueing at the host.
- **Word has been tested by a person on a Mac only.** Word for Windows, the Windows installer (built, unsigned, never run), a team server run by a team rather than by the test suite, and the screen-reader pass remain unverified ([checks still open](../contract-review/docs/VERIFICATION.md)).
- **Reviews and questions** through the `claude`, `anthropic` and `openai` routes no longer block the app and can be stopped; the evaluation-only `codex`, `muse` and `agy` routes still block it for the length of a call.
- **Security.** Everything listens on 127.0.0.1; another page served from localhost cannot call the API (Origin, Host and Sec-Fetch-Site are checked); API keys and the record signing key are kept out of any process the app runs. Not defended: a process running as the same user on the same computer can call the local API, as it can read the data folder. The model's store tools read as the signed-in lawyer, not only the document under review, so in team mode a prompt-injected model can read any team document that lawyer can; what it quotes is still verified and it cannot write. There is deliberately no MCP access to the store from outside a review. The [security review](../contract-review/docs/SECURITY-REVIEW.md) was done by the people who built the app; prompt injection is mitigated, not solved, and its live measurement (`tests/security/live-injection.mjs`) is still outstanding. No independent security review has been done.
- **Legacy names.** The code still uses the earlier name "GinChugger Legal" for the install folder, the data folder, the command name and a legacy keychain entry, so an upgrade finds existing data.
