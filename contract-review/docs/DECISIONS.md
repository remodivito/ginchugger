# Decisions made for this experiment

**Start with own-paper NDA redlines.** The application brief describes repetitive, low-stakes review. A narrow workflow makes it possible to inspect failures and demonstrate something useful within an application-sized project. Commercial coverage currently consists of two targeted extracts. It is not a production CLM.

**Put evidence beside the document.** A separate generated report is not the product commitment. Findings link to exact wording and explicit guidance. The lawyer can inspect, question, amend or dismiss the proposed response. Neither a “fits guidance” label nor a review note approves the agreement.

**Use an explicit provisional playbook.** Its authority is visible and editable. These are illustrative demonstration assumptions, not any organisation's policy. Historical reconstruction and automatic learning are not prerequisites. A human can turn a review observation into reusable guidance deliberately; the example does not imply that every negotiated concession should become a standing rule.

**Keep the engines visibly distinct.** Sample mode replayed a recorded real review (product v2; the earlier bounded local rules moved to the benchmark as a trivial baseline); it was removed as a user-facing mode on 17 October 2026, and replay is now test infrastructure only. Live mode sends the full supplied text and enabled rules to a configured model. No retrieval infrastructure is required for this small input. Citation validation constrains outputs but does not validate legal reasoning. A provider failure does not become a disguised local answer.

**Separate changes from current concerns.** A supplied baseline supports comparison; recorded document revisions provide narrower evidence; neither supplies unseen negotiation history. Without a prior draft, assess current wording without inventing earlier positions, approvals or attribution.

**Treat context as part of the review.** An unchanged exception can defeat an apparently acceptable clause. Missing incorporated material can prevent a conclusion. The examples deliberately include these cases, as well as changes requiring no alert, so “flag everything” is not success.

**Build on an existing category honestly.** [Spellbook's first-party review](https://help.spellbook.legal/en/articles/13875622-first-party-playbooks-redline-review) is a close product precedent. This submission does not claim to invent playbook review. Its contribution is a bounded, inspectable implementation and a clear account of what was tested, what failed, and what evidence would justify extending it.

**Use public text, controlled changes and explicit limits.** The complete NDA-derived fixtures share one source family; their constructed reference answers have not been lawyer validated. Exact citations and expected issue coverage are necessary checks, but not evidence of general legal reliability or time saved. Native Word-host behavior and live-model quality must be verified separately before making those claims.
