GinChugger

An AI-assisted contract review tool for in-house legal teams.

Review an agreement

  1. Open your agreement in Word and open the GinChugger task pane.
  2. Press Review. The pane names the playbook it will use; change it if the document is a different kind of agreement.
  3. Work through the points, worst first: Apply writes a tracked change under your name, Dismiss records why. Ask about the draft at the foot of the pane. You remain responsible for decisions and edits.

Reviews need a model route, chosen in Settings · Models on the local server: the Claude CLI signed in on this computer, an Anthropic API key, or an OpenAI-compatible endpoint. The example playbooks are provisional and do not represent any organisation's policy.

If something does not work

Check that the local server is running and its HTTPS certificate is trusted. The Word integration requires WordApi 1.6. If the document has changed since the review, the pane says so; review again before applying a suggestion. Ambiguous locations and edits overlapping existing revisions require manual editing.

The repository includes setup instructions in docs/SETUP.md, Word-specific instructions in docs/WORD.md, and the current verification limits in docs/VERIFICATION.md. This is a local prototype; no hosted support service is provided.
